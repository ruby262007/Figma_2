# Wanderlust – Travel Discovery Website

A visually engaging travel website designed to inspire users to explore destinations around the world. Wanderlust showcases popular travel experiences through an image-focused interface, destination cards, and intuitive navigation.

## 🌍 Project Overview

Wanderlust is a frontend web development project that presents a travel agency landing page. It features an attractive hero section, curated destination cards, an About Us section, and a clean footer.

The project focuses on building a structured web layout, styling visual components, and adding interactive navigation using JavaScript.

## ✨ Features

- **Travel-focused Hero Section:** An engaging landing section with a background image, introductory content, and a call-to-action.
- **Featured Destinations:** Displays popular destinations including Maldives, Swiss Alps, Safari Adventure, and Tokyo City.
- **Destination Cards:** Includes destination images, descriptions, and starting price labels.
- **Interactive Navigation:** Mobile navigation menu with JavaScript toggle functionality.
- **About Us Section:** Introduces the travel platform and its purpose.
- **Back-to-Top Navigation:** Allows users to smoothly return to the top of the page.
- **Clean UI Design:** Uses consistent typography, spacing, colors, and visual elements.
